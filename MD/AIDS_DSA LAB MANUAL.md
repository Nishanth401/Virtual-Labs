Aim
To implement a Singly Linked List in Java and perform basic operations such as
insertion, deletion, searching, and traversal using a menu-driven program.
Algorithm
1. Start the program.
2. Create a class for the node containing data and a reference to the next node.
3. Initialize the head of the linked list as NULL.
4. Display a menu with the following operations:
o Insert a node
o Delete a node
o Search for a node
o Traverse (Display) the list
o Exit
5. Read the user's choice.
6. Perform the selected operation:
o Insert: Create a new node and insert it at the end of the list.
o Delete: Search for the specified node and remove it by updating the links.
o Search: Traverse the list and check whether the given element is present.
o Traverse: Visit each node from the head and display its data.
7. Repeat Steps 5 and 6 until the user selects Exit.
8. Stop the program.
Program
import java.util.*;
class Node
{
int data;
Node next;
Node(int data)
{
this.data = data;
this.next = null;
}
}
public class SinglyLinkedList
{
Node head = null;
// Insert at the end

void insert(int data)
{
Node newNode = new Node(data);
if (head == null)
{
head = newNode;
}
else
{
Node temp = head;
while (temp.next != null)
{
temp = temp.next;
}
temp.next = newNode;
}
System.out.println("Node inserted successfully.");
}
// Delete a node
void delete(int key)
{
if (head == null)
{
System.out.println("List is empty.");
return;
}
if (head.data == key)
{
head = head.next;
System.out.println("Node deleted successfully.");
return;
}
Node temp = head;
Node prev = null;
while (temp != null && temp.data != key)
{
prev = temp;
temp = temp.next;
}
if (temp == null)
{
System.out.println("Node not found.");
}

else
{
prev.next = temp.next;
System.out.println("Node deleted successfully.");
}
}
// Search a node
void search(int key)
{
Node temp = head;
int position = 1;
while (temp != null)
{
if (temp.data == key)
{
System.out.println("Element found at position " + position);
return;
}
temp = temp.next;
position++;
}
System.out.println("Element not found.");
}
// Traverse the list
void traverse()
{
if (head == null)
{
System.out.println("List is empty.");
return;
}
Node temp = head;
System.out.print("Linked List: ");
while (temp != null) {
System.out.print(temp.data + " ");
temp = temp.next;
}
System.out.println();
}

// Main method
public static void main(String[] args)
{
Scanner sc = new Scanner(System.in);
SinglyLinkedList list = new SinglyLinkedList();
int choice, value;
do {
System.out.println("\n===== Singly Linked List Menu =====");
System.out.println("1. Insert");
System.out.println("2. Delete");
System.out.println("3. Search");
System.out.println("4. Traverse");
System.out.println("5. Exit");
System.out.print("Enter your choice: ");
choice = sc.nextInt();
switch (choice)
{
case 1:
System.out.print("Enter element to insert: ");
value = sc.nextInt();
list.insert(value);
break;
case 2:
System.out.print("Enter element to delete: ");
value = sc.nextInt();
list.delete(value);
break;
case 3:
System.out.print("Enter element to search: ");
value = sc.nextInt();
list.search(value);
break;
case 4:
list.traverse();
break;
case 5:
System.out.println("Exiting the program...");
break;
default:
System.out.println("Invalid choice. Please try again.");
}
} while (choice != 5);
sc.close();
}
}

2a. Doubly Linked List
Aim
To implement a Doubly Linked List in Java and perform insertion and deletion at
different positions such as the beginning, end, and a specified position.
Algorithm
Insertion at the Beginning
1. Create a new node.
2. Assign the data to the new node.
3. Set the new node's next to the head.
4. If the list is not empty, set the head's prev to the new node.
5. Update the head to the new node.
Insertion at the End
1. Create a new node.
2. If the list is empty, make it the head.
3. Otherwise, traverse to the last node.
4. Set the last node's next to the new node.
5. Set the new node's prev to the last node.
Insertion at a Given Position
1. Create a new node.
2. Traverse to the node before the desired position.
3. Adjust the next and prev pointers of the surrounding nodes.
4. Insert the new node.
Deletion at the Beginning
1. If the list is empty, display an error message.
2. Move the head to the next node.
3. Set the new head's prev to null.
Deletion at the End
1. If the list is empty, display an error message.
2. Traverse to the last node.
3. Set the second last node's next to null.

Deletion at a Given Position
1. Traverse to the node to be deleted.
2. Connect the previous node to the next node.
3. Update both next and prev links.
4. Delete the selected node.

2b. Circular Linked List
Aim
To implement a Circular Linked List in Java and perform insertion and deletion at
the beginning, end, and a specified position.
Algorithm
Insertion at the Beginning
1. Create a new node.
2. If the list is empty, make the new node point to itself and set it as the head.
3. Otherwise, traverse to the last node.
4. Set the new node's next to the head.
5. Update the last node's next to the new node.
6. Make the new node the new head.
Insertion at the End
1. Create a new node.
2. If the list is empty, make the new node point to itself and set it as the head.
3. Otherwise, traverse to the last node.
4. Link the last node to the new node.
5. Set the new node's next to the head.
Insertion at a Given Position
1. If the position is 1, insert at the beginning.
2. Traverse to the node before the required position.
3. Insert the new node by updating the links.
Deletion at the Beginning
1. If the list is empty, display an error message.
2. If only one node exists, set the head to null.
3. Otherwise, traverse to the last node.
4. Update the last node's next to the second node.
5. Move the head to the second node.
Deletion at the End
1. If the list is empty, display an error message.
2. If only one node exists, set the head to null.
3. Traverse to the last node while keeping track of the previous node.
4. Set the previous node's next to the head.

Deletion at a Given Position
1. If the position is 1, delete from the beginning.
2. Traverse to the node before the required position.
3. Remove the node by updating the links.
4. Display an error if the position is invalid.

Aim
To implement Linear Search and Binary Search algorithms in Java and compare their
searching techniques and performance.
Algorithm
Linear Search
1. Read the number of elements in the array.
2. Read the array elements.
3. Read the element to be searched.
4. Start searching from the first element of the array.
5. Compare each array element with the search key.
6. If the current element matches the search key, display its position and stop the
search.
7. Otherwise, continue comparing the remaining elements until the end of the array.
8. If the search key is not found after checking all the elements, display "Element Not
Found."
9. Stop the program.
Binary Search
1. Read the number of elements in the sorted array.
2. Read the sorted array elements.
3. Read the element to be searched.
4. Initialize the variables low = 0 and high = n − 1.
5. Repeat the following steps while low ≤ high:
6. Calculate the middle index using mid = (low + high) / 2.
7. Compare the middle element with the search key.
8. If the middle element is equal to the search key, display its position and stop the
search.
9. If the search key is smaller than the middle element, update high = mid − 1.
10. Otherwise, update low = mid + 1.
11. If the search key is not found after the loop ends, display "Element Not Found."

Program
import java.util.Scanner;
public class SearchComparison
{
// Linear Search
static int linearSearch(int arr[], int key)
{
for (int i = 0; i < arr.length; i++)
{
if (arr[i] == key)
{
return i;
}
}
return -1;
}
// Binary Search
static int binarySearch(int arr[], int key)
{
int low = 0;
int high = arr.length - 1;
while (low <= high)
{
int mid = (low + high) / 2;
if (arr[mid] == key)
{
return mid;
}
if (key < arr[mid])
{
high = mid - 1;
}
else
{
low = mid + 1;
}
}
return -1;
}

{
Scanner sc = new Scanner(System.in);

{
arr[i] = sc.nextInt();

if (linear != -1)
{
System.out.println("Linear Search: Element found at position " + (linear + 1));

else
{
System.out.println("Linear Search: Element Not Found");

{
System.out.println("Binary Search: Element found at position " + (binary +

14a. Bubble Sort
Aim
To implement the Bubble Sort algorithm in Java and analyze its performance.
Algorithm
1. Read the number of elements in the array.
2. Read the array elements.
3. Compare each pair of adjacent elements in the array.
4. If the left element is greater than the right element, swap their positions.
5. Repeat the comparison and swapping process for all adjacent elements in each pass.
6. Continue performing passes until the entire array is sorted.
7. Display the sorted array.
8. Stop the program.
Program
import java.util.Scanner;
public class BubbleSort
{
public static void bubbleSort(int arr[])
{
int n = arr.length;
for (int i = 0; i < n - 1; i++)
{
for (int j = 0; j < n - i - 1; j++)
{
if (arr[j] > arr[j + 1])
{
int temp = arr[j];
arr[j] = arr[j + 1];
arr[j + 1] = temp;
}
}
}
}

{
arr[i] = sc.nextInt();
}
bubbleSort(arr);
System.out.println("Sorted Array:");
for (int num : arr)
{
System.out.print(num + " ");
}

}

14b. Merge Sort
Aim
To implement the Merge Sort algorithm using the Divide and Conquer technique and
analyze its performance.
Algorithm
1. Divide the given array into two halves.
2. Recursively sort the left half of the array.
3. Recursively sort the right half of the array.
4. Merge the two sorted halves into a single sorted array.
5. Continue this process until the entire array is completely sorted.
6. Display the sorted array.
7. Stop the program.
Program
import java.util.Scanner;
public class MergeSort
{
static void merge(int arr[], int l, int m, int r)
{
int n1 = m - l + 1;
int n2 = r - m;
int L[] = new int[n1];
int R[] = new int[n2];
for (int i = 0; i < n1; i++)
{
L[i] = arr[l + i];
}
for (int j = 0; j < n2; j++)
{
R[j] = arr[m + 1 + j];
}
int i = 0, j = 0, k = l;
while (i < n1 && j < n2)
{
if (L[i] <= R[j])
{

arr[k++] = L[i++];
}
else
{
arr[k++] = R[j++];
}
}
while (i < n1)
{
arr[k++] = L[i++];
}
while (j < n2)
{
arr[k++] = R[j++];
}
}
static void mergeSort(int arr[], int l, int r) {
if (l < r) {
int m = (l + r) / 2;
mergeSort(arr, l, m);
mergeSort(arr, m + 1, r);
merge(arr, l, m, r);
}
}
public static void main(String args[]) {
Scanner sc = new Scanner(System.in);
System.out.print("Enter number of elements: ");
int n = sc.nextInt();
int arr[] = new int[n];
System.out.println("Enter array elements:");
for (int i = 0; i < n; i++) {
arr[i] = sc.nextInt();
}
mergeSort(arr, 0, n - 1);
System.out.println("Sorted Array:");
for (int num : arr) {
System.out.print(num + " ");
}
sc.close();
}
}

14c. Quick Sort
Aim
To implement the Quick Sort algorithm using the Divide and Conquer technique and
analyze its performance.
Algorithm
1. Select the last element of the array as the pivot.
2. Rearrange the array so that all elements smaller than the pivot are placed before it, and
all elements greater than the pivot are placed after it.
3. Place the pivot in its correct sorted position.
4. Recursively apply the Quick Sort algorithm to the left subarray.
5. Recursively apply the Quick Sort algorithm to the right subarray.
6. Repeat the process until the entire array is sorted.
7. Display the sorted array.
8. Stop the program.
Program
import java.util.Scanner;
public class QuickSort
{
static int partition (int arr[], int low, int high)
{
int pivot=arr[high];
int i=low-1;
for (int j=low; j<high; j++)
{
if (arr[j] <pivot)
{
i++;
int temp=arr[i];
arr[i] =arr[j];
arr[j] =temp;
}
}
int temp=arr[i+1];
arr[i+1] =arr[high];
arr[high] =temp;

return i+1;
}
static void quickSort(int arr[], int low, int high)
{
if (low<high)
{
int pi=partition(arr, low, high);
quickSort(arr, low, pi-1);
quickSort(arr, pi+1, high);
}
}

15a. Separate Chaining
Aim
To implement a Hash Table using the Separate Chaining collision resolution
technique in Java.
Algorithm
1. Create a hash table of fixed size.
2. Initialize each index of the hash table with an empty linked list.
3. Read the key to be inserted into the hash table.
4. Compute the hash index using the hash function index = key % tableSize.
5. Insert the key into the linked list at the computed hash index.
6. To search for a key, compute its hash index and traverse the corresponding linked
list.
7. Display the contents of the hash table.
8. Stop the program.
Program
import java.util.LinkedList;
public class SeparateChaining {
static final int SIZE = 10;
LinkedList<Integer>[] table;
@SuppressWarnings("unchecked")
SeparateChaining() {
table = new LinkedList[SIZE];
for (int i = 0; i < SIZE; i++) {
table[i] = new LinkedList<>();
}
}
void insert(int key) {
int index = key % SIZE;
table[index].add(key);
}
boolean search(int key) {
int index = key % SIZE;
return table[index].contains(key);
}

void display() {
System.out.println("Hash Table:");
for (int i = 0; i < SIZE; i++) {
System.out.println(i + " -> " + table[i]);
}
}
public static void main(String[] args) {
SeparateChaining hash = new SeparateChaining();
hash.insert(15);
hash.insert(25);
hash.insert(35);
hash.insert(42);
hash.display();
System.out.println("Search 25: " + hash.search(25));
}
}

15b. Open Addressing
Aim
To implement a Hash Table using the Open Addressing (Linear Probing) collision
resolution technique.
Algorithm
Algorithm for Linear Probing
1. Create a hash table.
2. Read the key to be inserted.
3. Compute the hash index using the hash function.
4. Check whether the computed location is empty.
5. If the location is empty, insert the key into the hash table.
6. Otherwise, move to the next location using (index + 1) % table size.
7. Repeat the probing process until an empty location is found and insert the key.
8. To search for a key, follow the same probing sequence until the key is found or an
empty location is reached.
9. Display the contents of the hash table.
10. Stop the program.
Program
public class LinearProbing
{
static final int SIZE = 10;
int[] table = new int[SIZE];
LinearProbing() {
for (int i = 0; i < SIZE; i++)
{
table[i] = -1;
}
}
void insert(int key)
{
int index = key % SIZE;
while (table[index] != -1)
{
index = (index + 1) % SIZE;
}
table[index] = key;
}
boolean search(int key)
{
int index = key % SIZE;
while (table[index] != -1)

{
if (table[index] == key)
{
return true;
}
index = (index + 1) % SIZE;
}
return false;
}
void display() {
System.out.println("Hash Table:");
for (int i = 0; i < SIZE; i++)
{
System.out.println(i + " : " + table[i]);
}
}

15c. Rehashing Technique
Aim
To implement a Hash Table using the Rehashing Technique to reduce collisions and
improve performance.
Algorithm
1. Create a hash table with an initial size.
2. Insert the keys into the hash table.
3. Calculate the load factor by dividing the number of elements by the table size.
4. Check whether the load factor exceeds the specified threshold (e.g., 0.75).
5. If the threshold is exceeded, create a new hash table with double the size.
6. Recalculate the hash index for all existing keys.
7. Reinsert all the existing keys into the new hash table.
8. Continue inserting the remaining keys into the resized hash table.
9. Display the contents of the resized hash table.
10. Stop the program.
Program
